- **3-1-01**：
  1. 先分清楚：純色加白、加黑、加灰，各會得到哪一類色彩？
  2. 加白會讓色彩變亮，加黑則相反；色彩的名稱就跟著明暗走。
  3. 含灰的才叫濁色；這題不含灰、而且明度降低，想想相對於「明色」的那一類。
- **3-1-06**：
  1. 想想我們用哪三個性質來描述一個色彩的「相貌、明暗、鮮豔」。
  2. 這三個性質的英文簡稱合起來叫 HVC。
  3. 其他選項描述的是光的物理量或視覺條件，不是色彩本身的三個基本性質。
- **3-1-09**：
  1. 水墨畫只用黑墨，靠什麼變化畫出濃淡層次？
  2. 墨加水變淡、少水變濃——這改變的是色彩三要素中的哪一個？
  3. 黑、灰、白之間的深淺變化，就是這個要素的階段變化。
- **4-1-02**：
  1. 想想眼睛裡負責控制進光量的構造是哪一個。
  2. 它能放大或縮小瞳孔，功能就像相機的光圈。
  3. 位於眼球前段、決定眼珠顏色的環狀構造。
- **4-1-04**：
  1. 視網膜上有兩種感光細胞，分工不同。
  2. 一種感應明暗、一種負責分辨色彩，想想是哪兩種。
- **4-1-05**：
  1. 想想哪一種感光細胞在明亮環境下運作。
  2. 能分辨色彩的感光細胞是哪一種？
  3. 名字形狀像圓錐的那一種細胞。
