# 題庫內容審查 Rubric

> 定位：本 rubric 是 **LLM 初篩** 的判準，展開自 `spec/06-content-and-question-bank.md` §12「內容品質」。
> 它不取代 §12 規定的教師終審——LLM 產出報告，教師只看報告做最終確認。
> 結構層驗證（stable code 格式、選項數、正解唯一、欄位非空、XSS 過濾等 §5 十條）
> 已由 `scripts/content/validation-rules.mjs` 機器強制，**本 rubric 不重複檢查**。

## 輸入

- `artifacts/content/questions.csv`（`pnpm content:fetch` 產出，實際欄位：題號、章節、小節、題目、選項A–D、正確答案、答錯觀念解析）
- 本 rubric 全文
- 教材對照來源（T1，2026-08-08 定案）：**不設外部教材檔**——Sheet 內容即教師自課本提取的摘錄，來源可信。C3 因此檢查的是「轉錄品質」（字詞、邏輯有沒有寫錯），不是與外部教材比對。

## 判準條目

每題逐條判定，結果只允許 `PASS` / `FAIL` / `UNSURE`。無法從題目文字判斷的（如需看圖）標 `UNSURE` 交教師，不得猜測。

| ID | 判準 | FAIL 條件 | 嚴重度 |
|----|------|-----------|--------|
| C1 | 唯一合理答案 | 逐一論證每個錯誤選項「為何錯」；若任一錯誤選項在合理詮釋下也能成立，或正解在某常見情境下不成立 | BLOCKING |
| C2 | 解析正確且有解釋力 | 解析與正解矛盾＝BLOCKING；解析只重述正解、未解釋為何對／其他為何錯＝NON-BLOCKING | 見左 |
| C3 | 概念正確性（轉錄品質） | 分兩級：**邏輯／概念矛盾**（題目、正確答案、解析三者互相矛盾，或陳述與公認色彩學常識衝突）＝BLOCKING；**一般錯別字**（和者→何者、心裡→心理等，不影響概念）＝NON-BLOCKING；但**專有名詞誤植**（如 NSC→NCS——會讓學生學到錯誤名詞）仍屬 BLOCKING。模型知識與內容衝突但無法確定何者為誤時，標 UNSURE 交教師，不得逕判 FAIL | 見左 |
| C4 | 誘答選項合理性 | 錯誤選項應對應可辨識的混淆點或常見迷思；明顯荒謬、與題幹無關的湊數選項 | NON-BLOCKING |
| C5 | 用語符合課程與年級 | 基準（T2）：以技高設計群一年級教科書出現過的術語為界（明度、彩度、色相環等屬界內）；超綱術語（如 CIELAB、光譜功率分佈）僅在題幹／解析未先定義時算違規 | NON-BLOCKING |
| C6 | 不以色覺為唯一線索 | 作答必須依賴分辨顏色本身、且題目未提供文字／標籤／數值輔助（若該題教學目標就是色彩辨識，須標記為刻意例外並交教師） | BLOCKING |
| C7 | 圖片教學合理性（有 media 的題） | alt text 或圖說未傳達教學重點（僅寫「圖片」）；或題目依賴螢幕間會漂移的細微色差。匯出資料無 media 欄位時略過本條並在報告註記「C7 無資料」 | NON-BLOCKING |
| C8 | 作答秒數合理性 | 基準（T3）：全部題目一律 20 秒（本題庫幾乎無計算題）；偏離即回報。目前 questions.csv 未含秒數欄位——無資料時略過本條並在報告註記「C8 無資料」 | NON-BLOCKING |

## 輸出格式（固定）

```
VERDICT: PASS | FAIL
BLOCKING:
- <題目 stable code> [C#] 一句理由（引用題目或解析原文片段）
NON-BLOCKING:
- <題目 stable code> [C#] 一句理由
UNSURE（交教師）:
- <題目 stable code> [C#] 無法判定的原因（如：需目視圖片）
統計: 共 N 題；有問題題數 M；finding 數：BLOCKING x, NON-BLOCKING y, UNSURE z
```

統計口徑：x/y/z 計 **finding 數**（一題可命中多條），M 計**題數**。已列管（import-fixes.json 或先前審查紀錄）但表上尚未修正的項目**照常計入**並加註 `[已列管]`——列管不等於已修，消失的 finding 會造成漏修。

規則：

- 每條 finding 必須含 stable code＋判準 ID；給不出具體題目的意見一律不輸出。
- 逐題檢查，不得抽樣；同一題可命中多條。
- reviewer 唯讀：不得修改 CSV、Sheet、DB 或本 rubric；發現 rubric 本身的缺陷，寫在報告末尾「rubric 回饋」節。
- 任何 BLOCKING 存在即 `VERDICT: FAIL`；FAIL 的題目在教師修表（Google Sheet SSOT）前不得進入 `content:import`。

## 教師終審職責（不可自動化）

1. 裁決全部 `UNSURE` 項與 C6 的「刻意例外」。
2. 抽查 LLM 判 PASS 的題目（建議每批 ≥10%），防同模型盲點。
3. 維護 T1–T3 基準（已定案；認定方式變更時更新本檔）。
4. 最終發布決定權在教師；LLM 報告只是輸入。

## 教師基準（2026-08-08 定案）

- **T1** 不設外部教材檔：Sheet 內容即課本摘錄，C3 檢查轉錄品質（錯字、邏輯矛盾、常識衝突），存疑一律 UNSURE 交教師。
- **T2** 以技高設計群一年級教科書術語為界；題幹／解析有先定義的超綱術語豁免。
- **T3** 全部題目一律 20 秒；匯出檔無秒數欄位時 C8 略過並註記。
