# ColorPlay × 日式 RPG 像素風全站改版 — 設計規格

- 日期：2026-07-31
- 狀態：已核准（owner 2026-07-31）
- 來源：2026-07-30 深夜 owner 多輪 brainstorming 定案（企劃參考 artifact：`claude.ai/code/artifact/3d49ea25-dbc3-498b-a637-81f2f0cfdded`）
- 範圍：**純表現層改版**。狀態機、RPC、RLS、ledger、計分規則（`rules_version`）與路由結構一律不動。

## 1. 目的

把既有平台（11 個 feature 模組、20+ 畫面、Live 即時課堂）的視覺與敘事整套翻譯成 16-bit 日式 RPG 像素世界，以世界觀一致性強化學習動機。本設計取代 0728 淡彩與 0730 奶黃頁底的視覺裁定（owner 已於 0730 深夜討論中確認方向；正式核准以本文件審閱通過為準）。

## 2. 世界觀：色彩王國

「色彩原理」課程即魔法體系：色相＝元素屬性、明度彩度＝法力強弱與純度、配色原理＝合成魔法。學生＝見習色彩法師；教師＝賢者。

| 既有系統 | RPG 對應 |
| --- | --- |
| 品牌三色（coral／cobalt／jade） | 三原色寶石（聖物，貫穿標題、HUD、頒獎台） |
| XP／Token（ledger） | 經驗值／金幣 G |
| Blook／頭像外框 | 夥伴（從魔）／裝備 |
| 章節／子主題 | 大陸／地城樓層 |
| 錯題本／補救練習 | 魔物圖鑑／復仇戰 |
| ColorPlay Live（速度計分 150） | 公會團體戰（ATB 行動條） |
| 三色精靈（新角色） | NPC 導師：紅／藍／綠各管一個講解領域 |

## 3. Owner 已定案的五項決議

1. **地圖解鎖＝軟鎖**：所有關卡永遠可點，僅視覺引導推薦路徑。節點四態直接映射 `get_learning_progress` 的 status：`not_started`＝灰霧、`learning`＝微光、`developing`＝全亮、`mastered`＝金色。零後端工程；「未開放」僅指未 published 內容。
2. **地圖層級＝兩層**：世界地圖（`/app/missions`＝章節大陸）→ 地城樓層（`/app/chapters/:id`＝子主題）。路由與資料層級不動；「進入大陸」以場景轉場表現（日景羊皮紙 → 地城冷色）。
3. **NPC 導師＝三色精靈**：同一基底 sprite 換色＋小配件差異（素材成本約 1.3 隻）。用於回饋講解、標題畫面、頒獎台。
4. **再挑戰**：計分 session 內只給「下一題」；重答一律走錯題本復仇戰（不計排行、可帶提示、不動 `rules_version`）。
5. **排行榜**：維持全期累計，不做週／月切換；純視覺改造為公會佈告欄。

## 4. 像素視覺系統

### 4.1 調色盤

全站收斂約 48 色主調色盤，每場景取一段色階。品牌三色（`#C73A3F`／`#3056D8`／`#22A06B`）保留為最高飽和層，僅用於寶石、關鍵行動、計分。基準色：夜空窗 `#171C3F`、羊皮紙 `#F6EED8`、金幣金 `#B8862F`。日／夜雙場景：村莊與世界地圖＝暖色日景；戰鬥、Live、投影幕＝夜空 navy（承接現行 Live 投影墨色舞台例外，改版後成為正規邏輯）。

**落地鐵律：色彩僅定義於 `src/styles/tokens.css`，同批同步 `tokens.test` 釘值；不得散落 raw hex。**

### 4.2 視窗與邊框

- 單一「對話窗」元件走天下：深藍夜空底＋白色雙線框（9-slice），用於題目窗、系統訊息、NPC 對話、購買確認。
- 零圓角、階梯直角；陰影用硬位移（`box-shadow: 4px 4px 0`）不用模糊；素材 `image-rendering: pixelated`。
- 8px 基準格；sprite 以 16／32px 繪製後整數倍放大；間距落在 4px 倍數。

### 4.3 字型

- 繁中標題與短文：**Cubic 11（俐方體 11 號，OFL）**，子集化自架，以 11 的整數倍尺寸使用；內文渲染不小於 16px。
- 拉丁點綴：Press Start 2P（徽標、關卡編號）；計分數字 `tabular-nums`。
- 長段說明文（教師端報表等）退回 Noto Sans TC；fallback 鏈明確寫死。

### 4.4 動效與音效

- `steps()` 階梯緩動；2–4 幀 sprite loop；時長 150–300ms；`prefers-reduced-motion` 降級為純文字回饋。
- 戰鬥特效三拍鐵律（server-authoritative）：**按下選項→揮刀（樂觀演出）→伺服器判定→命中／MISS**。回應抵達前不得顯示對錯；逾時＝魔物反擊。
- 音訊沿用 Live 既有 Ambient Loop／Cue 架構，全面 chiptune 化。
- 動畫只動 transform／opacity。

### 4.5 素材生產

- 魔物依「子主題家族＋palette swap」設計：同基底換色相＝同家族不同關卡，兼作色彩教學素材。
- 資產規格：16／32px、命名與存放規範於 P0 定案；spritesheet 合圖。

## 6. 品質與約束

- 無障礙底線：文字對比 4.5:1、觸控 44px、鍵盤焦點可見、`prefers-reduced-motion`；像素字內文 ≥16px。
- 驗證兩端：手機 375px 與教室 1080p 投影實測；design-audit 截圖基準全面重拍。
- 已刪除功能（assignments、班級進度頁等 0730 裁定）不因換皮復活。
- 回饋頁講解內容源＝`questions.explanation`（題庫 SSOT＝owner Google Sheet，44 題已同步；`4-1-09` 待教師裁定，該題暫用庫內舊版）。
- Live `screen_only` 裁剪、加入碼雜湊與節流等安全機制不變。

## 7. 實作批次

- **P0 前置**：本文件核准 → 更新 `spec/07-ui-visual-system.md`（normative 視覺基線）＋`CONTEXT.md` 詞彙（三色精靈、對話窗、寶箱結算）＋新增 ADR（記錄推翻 0728／0730 視覺裁定）→ tokens 新調色盤＋對話窗元件＋Cubic 11 子集 → 素材規格與首發素材。
- **批次①** 世界觀定調：標題／註冊／密碼頁＋村莊廣場大廳。
- **批次②** 核心循環：戰鬥＋寶箱結算。
- **批次③** 地圖與回饋：世界地圖＋地城樓層＋三色精靈回饋。
- **批次④** 村莊設施：商店／圖鑑／佈告欄／殿堂。
- **批次⑤** Live 與高塔：團體戰＋投影幕＋教師端。

每批於 worktree 執行，gate＝`pnpm lint && pnpm typecheck && pnpm test`＋design-audit 截圖＋375px 驗證；過 gate 才合併上線。批次順序可依素材產能微調，但批次①必須最先（定調）。

## 8. 風險

| 風險 | 對策 |
| --- | --- |
| 像素素材產能（最大時程風險） | 家族＋換色策略壓量；P0 先鎖規格；素材未齊的批次順延不搶跑 |
| CJK 像素字型載入量 | 子集化＋只在標題短文使用；內文可退 Noto Sans TC |
| 投影可讀性 | 批次⑤ 前現場 1080p 實測；投影幕字級獨立放大 |
| 測試與截圖基準大量翻新 | 每批只重拍該批畫面；tokens.test 同批更新 |
