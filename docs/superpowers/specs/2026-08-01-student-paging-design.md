## 1. 共用機制：GamePager（像素風水平分頁器）

- 新元件 `src/components/ui/game-pager.tsx`：把子項清單切頁，一次顯示一頁。
- 操作：左右像素箭頭鈕（≥44px、RpgWindow 語彙）＋頁碼指示（`第 n / N 頁`文字＋●○○ 點列）；鍵盤 ←/→；不做滑動手勢（批後評估）。
- **分頁僅於溢出時出現**：資料量在單頁容量內＝不渲染分頁 chrome、DOM 與現行等價 → 既有 e2e（項目可見性/文字斷言）在測試種子資料量下自然存活；資料超量才切頁。
- 換頁動畫只動 transform/opacity，`prefers-reduced-motion`＋`data-reduced-motion` 雙通道＝瞬切。
- 分頁狀態純前端 state（不進 URL、不進 storage）；無障礙：分頁容器 `aria-live="polite"` 頁碼播報、箭頭 disabled 態明確。
- 每頁容量隨舞台寬度計（CSS grid 固定行數×欄數，非 JS 量測優先）。

## 3. 品質約束（沿外殼批）

- 44px 觸控、對比 ≥4.5:1 rendered 實測、禁 transform:scale() 適配、console 0。
- e2e 依賴盤點 task 先行（同外殼批模式）：grep 各頁項目可見性斷言，確認測試種子資料量不觸發分頁；若有觸發（如 shop 種子 >8 件），該斷言顯式同步，不得靜默弄紅。
- 驗證：真跑三情境（1440×900／812×375／375×812）＋箭頭座標點擊換頁＋鍵盤換頁＋reduced-motion 兩通道瞬切。
- 「無縱向卷動」為目標非鐵律：內容固有高度（如錯題組標題+分頁器）超過 375 高的橫向手機時允許 scene 內短卷動，但整頁清單不得再是長卷。

| 風險                              | 對策                                         |
