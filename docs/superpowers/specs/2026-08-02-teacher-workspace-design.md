# ColorPlay 批⑤b 教師端整體優化 — 設計規格草案

- 日期：2026-08-02
- 狀態：**草案待 owner 核准**
- 來源：owner 0801「在 Live 課堂頁面的實作，要到教師端做一個整體的優化。整體風格不錯，但還需要修正」＋JRPG spec §6 批次劃分（教師工作區／教學分析／班級管理／Live 主持台內容級優化）＋外殼批 debt 移交清單
- 範圍：**表現層＋教師端內容重排**。路由、API、RPC、計分、finalize、rules_version 不動；載重字串鐵律沿前批（結構性斷言變更須經盤點 task 顯式同步）。

## 1. 設計原則

1. **像素濃度上限三成**（JRPG spec 既定）：教師端＝「賢者工坊」語彙——夜窗小卡、羊皮紙表格框、金色強調**只用在 chrome**（標題列/卡框/按鈕），資料區（表格/圖表/數字）維持高可讀性淺底深字，不做像素字體。
2. **與學生端同一舞台**：外殼批已把教師端包進滿版舞台＋底部 HUD；本批只做內容層。
3. **資料密度優先**：教師頁是工作介面——表格不分頁改卡（沿外殼批容器級 overflow 守門）；長「清單」才用 GamePager（沿分頁批元件）。

## 3. 外殼批移交 debt（本批處理）

1. 教師 HUD 指令列：4 項改一致樣式＋`NavLink` active 態（現為 Link 無 active、兩級視覺無據）——**注意：Link→NavLink 屬結構變更，需盤點 e2e**。
2. `aria-controls="hud-menu-panel"` 收合時 dangling → 收合時動態移除屬性或面板恆掛 DOM 以 hidden 切換。
3. hud-menu click-outside 關閉＋開啟時焦點移入面板（輕量 focus 管理）。
4. **不含**：toast 錨定（ToastProvider 掛載點搬移=行為層，另議）；login-page（平行 session 檔）；skip-link 卷動邊界（低影響）。

## 4. 紅 spec 前置（sizing task，非本批必修）

assignments-live／live-advanced 重寫 session 互動模型＋learning-experience 同構過時：本批含**一個 sizing 盤點 task**（逐 spec 列出與現行 UI 的斷差、重寫工作量估算、能否分段），產出報告供 owner 決定併本批尾段或另立批次。**預設不在本批重寫**（避免範圍爆炸）。

## 5. 品質約束（沿前批全套）

44px 觸控、對比 ≥4.5:1 rendered 實測（含表格在新框語彙內）、禁 transform:scale()、動畫只動 transform/opacity＋雙通道、console 0、盤點 task 先行（教師端 e2e：teacher-content.spec／classroom-leaderboard／live-smoke 教師段＋單元測試結構斷言）、commit 隔離（平行 session 檔清單沿前批）、gate 全電池（教師帳號真跑三情境）＋opus 終審。
