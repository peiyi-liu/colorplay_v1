## 1. 範圍與已裁定內容

### 1.1 LivePresenter 視覺與流程要求

`src/features/live/components/live-presenter.tsx` 的視覺與流程要求（owner 2026-08-10 裁定）：

- **不得有頁面層級的上下或左右滾動空間**——投影畫面在課堂實際使用情境下必須完整可見，不需要捲動。
- **不得裁切畫面中的任何物件**——目前已知會裁切的元素（若有）需要在改版時排除裁切。
- **文字呈現需要更清楚明顯**——字級/對比/排版需重新設計，確保投影到教室螢幕時仍清晰可讀。
- **正確答案顯示需要更明顯、但不誇張的效果**——目前的視覺回饋強度不足或需調整，具體效果設計於實作階段搭配前端 UI skills 產出。

**明確聲明**：owner 未指出任何具體的按鍵位置/主持流程步驟/RPC 呼叫時機問題。本輪裁定的優化範圍**僅限上述視覺/呈現層面**；若實作階段發現具體的按鍵/流程/RPC 問題，另案提出，不在本文件範圍內預先假設。

### 1.2 教師端新統計資料：學生進度頁 Live／自主正確率

於 `/teacher/classes/:classroomId/members/:memberRef`（學生進度頁）新增「Live 參與紀錄」區塊，正確率拆分為「課堂 Live」與「課後自主」兩欄。計算規則（owner 2026-08-10 裁定）：

- **分母**：不排除逾時未作答的題目——逾時未答的題目照樣計入分母。
- **分子**：只算完全正確的答案，不採計部分給分（未來若有部分給分機制，需另案重新裁定此規則）。
- **時間範圍與版本**：正確率以**當前內容版本**為準；跨版本後，舊版本累積的資料**不重新計算**（維持原版本當時的計算結果，不追溯套用新版本規則）。
- **Timeout 計分**：逾時未答視為錯誤（計入分母、不計入分子）。
- **Reconnect 計分**：斷線重連後補答，補答結果算數（視為正常作答）。

### 1.3 取消場次／非正式結算的呈現

- 教師端「Live 參與紀錄」清單**要顯示**已取消／非正式結算的場次，標記為「取消」。
- **與 `docs/roadmap-colorplay-next.md` 已核准規則的關係**：該規則規定取消的 Live Session 在學生端正式紀錄排除完成/排名/連擊/勳章/精熟度/班級平均效果。**此規則管的是學生端官方記錄範圍，不限制教師端這份內部參考清單**——owner 2026-08-10 明確裁定：教師端清單裡，取消場次的「名次」欄位**仍顯示伺服器實際計算出的名次**（供教師內部參考），不因該場次被標記取消/非正式而留空。

### 1.4 平手與缺席的名次呈現

- **平手**：並列最高名次（同分者共享該分數區段裡較高的名次號碼，例如兩人並列第 2 名，下一位是第 4 名，不是第 3 名）。此規則適用於正常（非取消）場次；取消場次見 1.3 節。
- **缺席**：學生中途離線/缺席，計入「參與」。

### 1.5 隱私／RLS 邊界

本文件涵蓋的新統計資料（Live/自主正確率拆分、Live 參與紀錄），僅該班級的**擁有教師**（owner teacher）可見，不對其他有權限查看該學生的教師開放。
